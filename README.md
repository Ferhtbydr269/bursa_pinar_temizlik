# Bursa Pınar Temizlik — Kurumsal Web Sitesi

Bursa'da hizmet veren bir temizlik firması için hazırlanmış, SEO odaklı kurumsal web sitesi.

🔗 **Canlı site:** https://bursa-pinar-temizlik.vercel.app

**Yığın:** Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion · Vercel

## Sayfalar

| Sayfa | Yol |
|---|---|
| Ana sayfa | `/` |
| Hizmetler | `/hizmetler/insaat-sonrasi` · `/ofis-ev` · `/villa` · `/fabrika` · `/dis-cephe` · `/cami` |
| Fiyat hesaplama | `/fiyat-hesapla` — anlık fiyat tahmini aracı |
| Blog | `/blog` · `/blog/[slug]` |
| Hakkımızda · İletişim | `/hakkimizda` · `/iletisim` |

## Çalıştırma

```bash
npm install
npm run dev   # http://localhost:3000
```
